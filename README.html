agnoforge · Go 1.25 · DuckDB

Market Data Acquisition

Downloads historical OHLCV bars from a provider (Binance), stores them exactly as returned, remembers what was asked for and what is missing, and serves them to other AgnoForge services as JSON or Parquet.

The problem it solves

Backtests silently lie when the bars underneath have holes. This service makes the holes explicit and queryable: before another service trusts a range it asks one question — is this range Complete? — and gets a yes/no backed by records, not hope.

Six words you need

Dataset

(Provider, Symbol, Timeframe). Only bars the provider actually returned.

Backfill

Acquire all bars of one Dataset over [start,end). Idempotent.

Coverage

Union of everything ever Backfilled. Outside it we say nothing.

Gap

Missing bars inside Coverage. Status: open · repaired · ignored · unrecoverable.

Repair

A Backfill aimed at one Gap's range.

Complete

The only question other services should ask before trusting a range.

Full ubiquitous language and the words to avoid: CONTEXT.md.

Get it running

go build ./cmd/agnoforge && go test -race ./...
AGNOFORGE_DB_PATH=/tmp/agnoforge.duckdb ./agnoforge serve      # http://localhost:8080

./agnoforge data backfill binance BTCUSDT 1m 2024-01-01 2024-02-01 -wait   # → 44,640 bars
./agnoforge data complete binance BTCUSDT 1m 2024-01-01 2024-02-01
./agnoforge data gaps     binance BTCUSDT 1m -status open
./agnoforge data query    binance BTCUSDT 1m 2024-01-01 2024-02-01 -o jan.parquet

Then open localhost:8080/playground/ — every operation as a form, with the request, the curl, the CLI equivalent, and the trace behind it. Nothing else to start.

HTTP API

GET    /providers
POST   /backfills                    {provider,symbol,timeframe,start,end}
GET    /backfills/{id}   DELETE /backfills/{id}
GET    /datasets/{p}/{s}/{tf}/coverage
GET    /datasets/{p}/{s}/{tf}/complete?start=&end=
GET    /datasets/{p}/{s}/{tf}/gaps[?status=]
GET    /datasets/{p}/{s}/{tf}/bars?start=&end=[&format=parquet|json]   # X-Gaps header lists open gaps
PATCH  /gaps/{id}                    {status: ignored|unrecoverable}
POST   /gaps/{id}/repair

Every response carries X-Trace-ID; the CLI prints trace: <id> on failure. Paste it into /playground/traces/{id}. Traces live in memory (last 256), so there is no Jaeger to run.
